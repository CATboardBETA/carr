# Contributing

**AI-assisted code or AI-generated code will not be tolerated**. This project has been written entirely by humans, and I intend to keep it that way. This rule is **non-negotiable**. Any issues or PRs in violation of this rule will be closed immediately.

Maintainers reserve the right to deny PRs for any reason, including suspected AI usage, poor code practices, rudeness, or not following code style.

Please create an issue before implementing any new features or fixing any bugs which take a lot of work, to prevent wasted time/duplicated effort.

Try to keep PRs isolated to just fixing one bug, or adding one new feature. 

Before submitting your PR, I'd recommend running `cargo fmt` (if you choose not to, a reviewer will request you do before your PR is accepted). 

I (CATboardBETA) am available on Discord `@catboardbeta`, feel free to message me with any additional questions.
