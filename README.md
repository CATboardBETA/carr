# `CArr`: *C*onstant-sized *Arr*ays

`carr` attempts to be a general-purpose tensor, matrix, and array library. **NOTE**: AI is not used in the development 
of this project, and PRs/issues generated by AI will not be considered.

# Installation
To install the latest version, simply run
```sh
cargo add carr
```
Or, manually add `carr="0.3"` to your `Cargo.toml` under the dependencies table.
